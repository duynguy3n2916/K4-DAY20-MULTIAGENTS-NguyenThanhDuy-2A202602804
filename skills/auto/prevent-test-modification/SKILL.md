---
name: prevent-test-modification
description: Use when ensuring that original test files remain unaltered during updates.
---
1. Always create new test files for any modifications or additions to tests.
2. Review the test directory before making changes to confirm no existing tests are altered.
3. Use version control to track changes and ensure original files are preserved.
4. Document any new tests added in a separate changelog or documentation file.
5. Run tests after modifications to verify that original tests pass without changes.

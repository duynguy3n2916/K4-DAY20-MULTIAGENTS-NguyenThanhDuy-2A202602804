---
name: generate-changelog-entries
description: Use when documenting changes and fixes in the project changelog.
---
1. For each fix or change, create a bullet point under the '## Unreleased' section in CHANGELOG.md.
2. Format each entry as '- fix(<function name>): <short description of the fix>'.
3. Ensure at least three entries are added for each set of changes.
4. Review the changelog for consistency in formatting and clarity.
5. Update the changelog immediately after changes are made to maintain accurate records.
